# 🛍️ Neo Mart App

A modern Flutter e-commerce application built completely from scratch with a clean architecture, premium UI, responsive layouts, smooth animations, and reusable widgets.

This project is independently developed to strengthen Flutter development skills and will continue to evolve with backend integration and advanced features.

## ✨ Features

- 🚀 Splash Screen
- 👋 Onboarding Screens
- 🔐 Login & Sign Up
- 🏠 Home Screen
- 🔍 Search Functionality
- 📂 Product Categories
- 🛍️ Product Cards
- 📄 Product Detail Screen
- 🛒 Shopping Cart UI
- ❤️ Wishlist UI
- 📦 Product Data Passing Between Screens
- 🧭 Named Route Navigation
- 📱 Fully Responsive Design
- 🎨 Premium Dark Theme
- ✨ Custom Animations
- ♻️ Reusable Widgets
- 🏗️ Built Completely from Scratch

## 🛠️ Tech Stack

- Flutter
- Dart
- Material Design
- Named Route Navigation
- MediaQuery (Responsive Design)
- AnimationController
- Tween Animations
- Custom Widgets
